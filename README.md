# 📚 BibliotecaMVC

Este projeto é um exemplo simples de aplicação em PHP utilizando o padrão de arquitetura MVC (Model-View-Controller). Ele simula uma biblioteca, onde é possível cadastrar e listar livros em uma estrutura organizada e de fácil entendimento.

# 🗂️ Estrutura do Projeto

📦 BibliotecaMVC/
* ├── index.php : Arquivo principal que orquestra o MVC
* ├── livro.php : Model: define a classe Livro
* ├── livroController.php : Controller: gerencia a lógica e os dados
* ├── livroView.php : View: exibe os livros cadastrados (opcional)
* └── README.md : Documentação do projeto

# 🔄 Funcionamento

## 🧠 Model (livro.php)

Contém a classe Livro, que representa os dados de um livro com atributos como título, autor, ano, etc.

## 🧭 Controller (livroController.php)

Gerencia a lógica de cadastro e armazenamento dos livros (em memória, sem banco de dados), e passa os dados para a view.

## 🖼️ View (inserida no index.php ou separada em livroView.php)

Responsável por exibir os livros na tela e mostrar o formulário de cadastro.

# 🎯 Objetivos do Projeto

* Demonstrar a separação de responsabilidades com o padrão MVC.
* Servir como base para projetos maiores com persistência de dados.
* Praticar lógica de programação e organização de código em PHP.
